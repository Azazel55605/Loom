# Component registry

The living inventory of every UI component in Loom. Conventions governing how
these are built live in [`UI_GUIDELINES.md`](./UI_GUIDELINES.md) and change
rarely; this file changes constantly.

The shared React UI and client logic live in `packages/ui-kit`. Web/frontend,
Desktop, and Mobile consume that package. Each installed app keeps only thin
router, persistence, and native-transport adapters.

| `ConnectorIcon` | `packages/ui-kit/src` | custom | — | web-frontend, desktop, mobile | Resolves `brand:`/`lucide:` icon references — see [`THIRD_PARTY_ICONS.md`](./THIRD_PARTY_ICONS.md).
