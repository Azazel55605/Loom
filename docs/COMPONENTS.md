# Component registry

The living inventory of every UI component in Loom. Conventions governing how
these are built live in [`UI_GUIDELINES.md`](./UI_GUIDELINES.md) and change
rarely; this file changes constantly.

The shared React UI and client logic live in `packages/ui-kit`. Web/frontend,
Desktop, and Mobile consume that package. Each installed app keeps only thin
router, persistence, and native-transport adapters.

| `SchemaForm` | `packages/ui-kit/src` | custom | — | web-frontend, desktop, mobile | A form generated from a JSON Schema document, so registering a connector type on the backend needs no frontend change: the add-connector dialog renders whatever `configSchema` it is handed, and action parameters go through the same component. Also exports `defaultsForSchema` and `validateSchemaValues`. **Minimal JSON Schema support: string, number/integer, boolean, and nested objects only.** `enum`, `array`, `oneOf`/`anyOf`/`allOf`, `$ref` and unrecognised types are rendered as a visible "not supported yet" note rather than silently dropped — a field quietly missing from a form is a setting a user can neither set nor see that they cannot set. | `ConnectorInstanceDialog` | `packages/ui-kit/src` | custom | — | web-frontend, desktop, mobile | One dialog for both adding and reconfiguring an instance, as with `GroupDialog` — the fields and validation are identical and only the request differs. | `ConnectorIcon` | `packages/ui-kit/src` | custom | — | web-frontend, desktop, mobile | Resolves `brand:`/`lucide:` icon references — see [`THIRD_PARTY_ICONS.md`](./THIRD_PARTY_ICONS.md). Never throws and never renders nothing: a connector is not broken because its icon is. **Brand icons are not tinted.** A `lucide:` icon is a line drawing inheriting `currentColor` and follows the accent like every other icon; a `brand:` icon is someone else's mark with its own palette, so it renders at natural colours on a neutral plate — the accent colours our surfaces, not their logo. A failed chunk load leaves the placeholder rather than throwing, since there is no error boundary here. |
